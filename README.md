# Thin-Film Optical Metrology and Tolerance Design

Infer coating thickness from optical measurements, test what those measurements can
identify, and evaluate coating performance under declared thickness tolerances.

**In development.** Project 5 of the semiconductor Python portfolio. No numerical
results or completed-release claims yet. The frozen scope and current state are in
[the development record](docs/PROJECT_PROGRESS.md).

V1 covers coherent isotropic planar films, polarized spectra and ellipsometry,
one/two-thickness inference, uncertainty and ambiguity diagnostics, one measured
reanalysis, a synthetic tolerance study and a focused interactive demonstration.

Original implementation is MIT licensed and AI-assisted. External reference and
measurement data retain their own licences and require explicit provenance.
