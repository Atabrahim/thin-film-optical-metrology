# Measurement and reference inputs

These files are inputs, not independent proof of thickness accuracy. No data were
smoothed, interpolated or repaired before archiving. The measured workflow explicitly
selects 400–800 nm; it reports the excluded rows.

## Measured ellipsometry: `raw/TiO2_400cycles.txt`

Source: [pyElli ALD TiO2 multilayer example](https://pyelli.readthedocs.io/en/latest/auto_examples/plot_02_TiO2_multilayer.html).
The source describes 400 ALD cycles of TiO2 on commercial SiO2/Si, measured with a
Sentech ellipsometer. Columns are wavelength (nm), Psi (degrees), Delta (degrees).
The file contains 1,227 measurements. Its header specifies 70.06° incidence; the
example's calculation uses 70°. This project uses the file's 70.06° value.

**Phase convention:** [pyElli's result definition](https://pyelli.readthedocs.io/en/latest/_modules/elli/result.html)
is `rho = tan(Psi) exp(-i Delta)`. Our API defines Delta as `+arg(rho)`.
The workflow explicitly converts `delta_api_deg = -delta_raw_deg` before fitting;
plots convert predictions back to the source convention. Raw and converted columns
are retained. This is a documented convention transformation, not a data correction.

Fixed dispersion comes from that same example. In its convention,
`n = n0 + 100*n1/lambda_nm² + 1e7*n2/lambda_nm⁴`:

| Film | n0 | n1 | n2 | Meaning |
| --- | ---: | ---: | ---: | --- |
| SiO2 | 1.452 | 36 | 0 | Example's fixed oxide dispersion |
| TiO2 | 2.22973557 | 461.689340 | 189.779575 | Fit reported by the source example |

The oxide thickness 276.36 nm and reported TiO2 thickness 24.8446396 nm are
**source-model results**, not certified measurements. TiO2 dispersion was estimated
from these same spectra. Reusing it makes our thickness extraction a conditional
reanalysis; agreement with the source is not independent validation. Cauchy is a
transparent-window empirical approximation (k = 0), not an absorption-edge model.

## Reference silicon constants: `reference/Si_Aspnes.yml`

[Pinned refractiveindex.info table](https://github.com/polyanskiy/refractiveindex.info-database/blob/c5c2f188e848453def5970e347399d653df2ffc2/database/data/main/Si/nk/Aspnes.yml),
revision `c5c2f188e848453def5970e347399d653df2ffc2`.

Source: D. E. Aspnes and A. A. Studna, *Physical Review B* 27, 985–1009 (1983),
[doi:10.1103/PhysRevB.27.985](https://doi.org/10.1103/PhysRevB.27.985).
The database specifies room-temperature Si, <111>, n type, 2.3e14 cm⁻³.
The database file explicitly carries CC0/public-domain terms. Its reference wavelengths
are in micrometres (converted to nm on import); n and k are dimensionless.
Range 206.6–826.6 nm. Interpolation is piecewise linear in n and k; extrapolation is rejected.

SHA256: `766489862d0d4dc6011e9f078e556a4a24fe79622bec0b1f1a80b297c84ce00d`.
These are reference material properties, not measurements on the ALD sample.

## Synthetic cases

Synthetic observations and assumed manufacturing variation are generated by the documented
workflow with explicit random seeds. They are never described as experimental data.
