# Changelog

## 0.1.0 — 2026-09-27

First complete release of the frozen V1 portfolio scope.

- Stable coherent s/p multilayer optics, explicit power and phase conventions.
- Cauchy/reference dispersion and auditable experimental import.
- Bounded one/two-thickness inference, multistart ambiguity and covariance diagnostics.
- Measured ALD TiO2/SiO2/Si reanalysis with model-sensitivity refits.
- Synthetic identifiability/recovery and antireflection tolerance studies.
- Reproducible API/CLI, four scientific figures and focused interactive demonstration.
- 38 automated checks; independent optical/inference benchmarks; package and CI verification.

Numerical verification is not a claim of calibrated thickness accuracy or industrial
process qualification. See the model, inference, provenance and case-study documents.
Development and validation execution were AI-assisted.
